### US-701 · Leave with everything, in the format I want
As a **Writer**, I want to export as Markdown, JSON or PDF in one tap, with the JSON lossless, so that the exit from Aroel is never a hostage situation. [§5.13, §8.1]

- Export includes **day records, ratings, tags and gratitude — not just entries.** ⚠ **[invariant — anything less is a broken export]** [§5.13]
- JSON is lossless and the screen says so. [§5.13]
- `GET /export?format=md|json|pdf`. [§7.2]
