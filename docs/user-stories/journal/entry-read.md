### US-502 · Read an entry the way a journal should read
As a **Writer**, I want serif typography on paper and a metadata footer, so that re-reading feels like re-reading, not browsing. [§5.5]

- Newsreader for the body. **Never Inter for the user's prose.** **[invariant]** [§6.2, AGENTS.md]
- Metadata footer: date, sentiment, tags. [§5.5]
- Edit and delete available; delete is soft for 30 days, then purged. **[invariant]** [§5.5, §8.2]
- Pinned entries float to the top. [§4.2]
