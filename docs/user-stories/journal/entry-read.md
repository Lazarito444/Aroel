### US-502 · Read an entry the way a journal should read
As a **Writer**, I want serif typography on paper, a metadata footer (date, program day, emotions, tags) and backlinks, so that re-reading feels like re-reading, not browsing. [§5.7]

- Newsreader for the body. **Never Inter for the user's prose.** **[invariant]** [§6.2, AGENTS.md]
- Edit and delete available; delete is soft for 30 days, then purged. **[invariant]** [§5.7, §8.2]
- Pinned entries float to the top. [§4.2]
