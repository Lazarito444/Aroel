# Aroel
Aroel is a personal journaling app focused on introspection, emotional tracking, and self-discovery. Capture your thoughts, express your feelings, reflect on experiences, and better understand your emotional well-being through a simple, private, and meaningful journaling experience.

## Docs

- [Scope & Design](docs/scope-and-design.md) — product positioning, v1 scope, domain model, screens, warm-paper design system, architecture, milestones.
- [User stories](docs/user-stories/README.md) — the stories of v1, one folder per module.

## Code

- [`mobile/`](mobile) — the Flutter client (iOS and Android). The auth module of milestone M1 is built; see [`mobile/README.md`](mobile/README.md).
- [`backend/`](backend) — the .NET server: the domain model, the identity split and the first migration. The HTTP endpoints are not there yet.
