# Trust — Voice & copy

Epic E7 · Milestone M6 · Source: [`../README.md`](../README.md)

### US-703 · Stay in the "not clinical" lane
As a **Writer**, I want copy that never diagnoses, triages, or guilt-trips me, so that a bad week isn't a customer-support incident. [§1.4, §6.5, §10 (open question 7)]

- All copy: second person, plain, unhurried. **No exclamation marks. No streak guilt. No "Oops!". No diagnosis language.** ⚠ **[invariants — store-risk constraint; review copy at screen level, not after]** [§6.5, §10.6]
- Offline panic states state what happened and what is safe: *"You're offline. Everything you write is saved here and will sync when you're back."* — that wording is spec. [§6.5]
- Mood/rating render tied to the ramp, which diverges around 2.5 so a bad week reads warm, not as an error state. [§6.6]
